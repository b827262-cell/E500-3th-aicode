   - follow redirects
   - 限速/timeout/retry
   - 避免重複下載
   - 可記錄 sha256、final URL、下載時間
5. robots/sitemap：正式大量抓取前檢查 robots.txt；若無 sitemap 或規則無法取得，記錄結果。不得繞過登入、驗證碼、存取限制或 robots 禁止項目。
6. 加入低頻率請求、User-Agent、timeout、有限 retry、cache/增量更新的基本設計。避免對來源站造成負擔。
7. 結構化輸出至少包含 JSON；如架構合適可同時提供 SQLite。建議資料目錄：data/raw、data/normalized、data/state，但以 repo 現有規範為準。
8. 提供可重複執行 CLI，例如：
   python -m <module> crawl
   python -m <module> crawl --download-pdfs
   實際命令依專案結構決定，但 README 必須寫清楚。
9. 加入 parser/unit tests，使用 fixtures/mocked HTTP，不讓一般測試依賴 live 網路。另提供一個明確的 live smoke test 指令，若網路可用則執行並記錄結果。

   - pages/records 由 live 頁面動態取得，不硬編碼 14/15 頁或 210/216 筆。
   - 年度、科目、URL 欄位不可靜默丟失。
   - passing rate 能正規化成 numeric 或同時保留 raw value。
11. 不儲存任何秘密資訊、token、cookie；不要把來源網站的個資表單資料納入爬取。
